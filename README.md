
# Space Invaders + Pong
## What this is
2 Games; Pong and Space Invaders
I made it because I have always loved Pong since it was one of the first video games and Space Invaders because I likes Space Invaders for it's simplicity and ease of play, yet still gives me a challenge. I tried to make Space Invaders as similar to the original 1978 version as possible, but it is still not an exact replica.
Controls are not listed in-game for Space Invaders to mimic the original arcade experience, but they are listed below
## Instructions
1. Go to [this link]([https://example.com](https://s125371.pyscriptapps.com/s125371-retro/latest/))
2. Select the game you want

### Controls for Space Invaders
* **Arrow Keys(left and right)**: Movement
* **Space**: Shoot
* **Enter / X**: Start game (requires at least 1 coin)
* **Z**: Insert Coin

### Controls for Pong
* **Arrow Keys(up and down)**: Movement
* **Enter**: Start Game
